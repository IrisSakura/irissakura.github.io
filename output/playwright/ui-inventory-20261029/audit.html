建议先归并的范围

  1. 先统一基础控件：按钮、输入、标签、卡片、折叠控件和选中态。定义少量明确变体，避免由页面位置隐式改变组件形状。
  2. 统一信息层级：标题档位、正文宽度、行动链接层级、章节留白；不要把标题大小差异当作唯一的项目区分方式。
  3. 保留项目识别：六项目的颜色、角色、内容图示可以继续不同；背景、边框、阴影和装饰数量需要受同一套规则约束。
  4. 最后收拢覆盖：当前 shared → 页面样式 → grammar → notebook → 局部规则共同决定输出；把最终规则收回组件所有者，再讨论装饰细节。

这份清单提供现状与判断，不代表已批准改版。现有项目构图差异在设计文档中有明确意图；Wisteria 的当前配置已改为 technical-notes，应在后续设计中明确是否保留该特例。
