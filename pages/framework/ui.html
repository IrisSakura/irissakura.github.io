PROGRESSIVE ARCHITECTURE COST

Paradigm-Neutral UI

Direct、Binding、MVVM 与 Structured UI 是递增成本的选择，不是从简单到高级的等级表。

阅读本页返回 Engineering Hub

WHAT THIS SOLVES

解决什么

让 UI 状态、绑定与表现层可以按复杂度组合，而不强迫所有页面进入同一种范式。

WHAT THIS COSTS

付出什么

支持多条路径意味着需要共享契约、适配层和跨范式回归测试。

WHERE IT DOES NOT APPLY

哪里不适用

简单、短寿命、低状态页面通常不需要 MVVM；复杂多人协作页面才可能收回其成本。
