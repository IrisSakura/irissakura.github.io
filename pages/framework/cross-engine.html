PORTABLE CORE → ENGINE ADAPTER

Cross-Engine 的核心不是多一个平台标签

先把时间、配置、并行、存档等语义从引擎对象中剥离，再由 Unity 或 Godot Adapter 承担生命周期和平台 API。

WHAT THIS SOLVES

解决什么

让可迁移规则保持 BCL-only / no-engine，同时允许不同引擎以自己的宿主与资源语义接入。

WHAT THIS COSTS

付出什么

需要显式端口、Adapter 测试和能力矩阵；平台特性不能偷渡进 Core。

WHERE IT DOES NOT APPLY

哪里不适用

高度依赖单一引擎渲染、Editor 或资产序列化的能力应留在平台层。
