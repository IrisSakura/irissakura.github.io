FRAMEWORK PLAYGROUNDS

六个独立玩法项目

六个独立 Unity 项目分别探索塔防、时间管理、工厂物流、生态收集、刷装战斗与生活模拟，让 Framework 能力落到可理解的玩法循环里。

01塔防原型

Route-Wave TD

建塔、封锁路线与三波敌人组成一局紧凑的塔防循环；结束后可以清理状态并开启全新战局。

核心系统

  • 路线封锁
  • 波次推进
  • 建造窗口
  • 胜负结算
02时间管理原型

Kitchen Shift

在一个短班次里安排多道菜并同时服务顾客；配方前置、等待与流失共同形成时间压力。

核心系统

  • 并行烹饪
  • 配方前置
  • 顾客耐心
  • 班次结算
03工厂物流原型

Railworks Factory

围绕铁路联运组织生产与发运；堵塞出现时恢复调度，并控制持续运行产生的历史记录。

核心系统

  • 生产排程
  • 铁路发运
  • 堵塞恢复
  • 历史清理
04生态收集原型

Living Bestiary

在季节推进中模拟生态变化和生物遭遇，并用检查点存档与备份恢复延续探索进度。

核心系统

  • 季节循环
  • 生物遭遇
  • 检查点存档
  • 备份恢复
05刷装战斗原型

Ashfall Loot Run

在三次遭遇中用确定性掉落和伤害预算完成一轮刷装；权威拾取与重复拒绝让战利品状态保持可信。

核心系统

  • 三段遭遇
  • 确定性掉落
  • 伤害预算
  • 拾取幂等
06生活模拟原型

Willow Hearth

把小时推进、NPC 日程、农田成长、天气预报与出货结算串成可重复的一日经营循环。

核心系统

  • 小时推进
  • NPC 日程
  • 农田成长
  • 出货结算
