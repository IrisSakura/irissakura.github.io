    研究判断

    理解引擎机制、游戏设计与当前约束。

    显式授权

    把研究提案、目标和执行权限变成可复查合同。

  3. 03

    框架沉淀

    只把跨项目复用的结论沉淀为稳定边界。

  4. 04

    游戏验证

    用可玩循环、截图和限制校验实际价值。

Iris Shelf

事实更新 · 2026-08-30源仓推送公开投影 · 复核 2026-08-30

Iris Engineering 的独立 local-first 桌面伴侣，为私有项目提供组织、只读 Git 健康、类型化启动预览与可选 companion 状态，而不成为 Shell、Git 客户端或控制面。

职责
桌面产品 / 本地开发入口
目标
让本地开发项目从一个安静、可恢复、失败隔离的桌面入口开始，同时保持路径、笔记和项目状态完全由本机 owner 掌控。
证据
完整 v1 桌面功能面与只读 Git 健康；unsigned Universal app/DMG 本地构建；Iris companion v1 producer、consumer 与 rebuilt packaged native 本地互操作验证；版本化状态、备份与恢复合同
限制
尚未签名、公证或公开发布；Windows runtime 与安装生命周期尚未验证；Personal Beta 常态使用证据尚待积累
下一步
按隐私安全协议开始 Personal Beta 常态使用；积累恢复、耐久与实际工作流证据；在独立发布门禁下评估签名、公证与分发

Sakura Framework

事实更新 · 2026-08-30源仓推送公开快照 · 复核 2026-08-31

面向 Unity 游戏项目的模块化开发框架，将研究中可复用的生命周期、运行时服务与玩法规则沉淀为可组合能力。

职责
架构与框架开发
目标
让新项目以明确的最小依赖组合进入玩法验证，同时公开区分稳定、预览与实验能力。
证据
由权威仓库生成的公开能力快照；Catalog 模块与生命周期分布；人工复核的 Supported 能力与稳定采用路线；Semantic Combat Runtime V2 本地验证与全框架静态架构审查
