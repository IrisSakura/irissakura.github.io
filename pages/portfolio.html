02 · 框架与工具 · 持续演进

Sakura Framework

面向 Unity 游戏项目的模块化开发框架，将研究中可复用的生命周期、运行时服务与玩法规则沉淀为可组合能力。

职责
架构与框架开发
目标
让新项目以明确的最小依赖组合进入玩法验证，同时公开区分稳定、预览与实验能力。
证据
由权威仓库生成的公开能力快照；Catalog 模块与生命周期分布；人工复核的 Supported 能力与稳定采用路线
限制
多数能力仍处于 Preview 或 Experimental；站内教程不绑定发布版本，正式项目仍需从官方 stable snippet 锁定 tag 或 commit
