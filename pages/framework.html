框架定位

这是一个服务于长期游戏开发的 Unity 模块化框架。规模只说明研究和覆盖范围，不代表所有能力都适合生产采用；生命周期才是当前成熟度事实。

MATURITY BEFORE SCALE

先看成熟度，再看规模

140 个 Package 中只有 4 个处于 Supported；Preview 和 Experimental 不应被解释为同等稳定的生产能力。

4Supported

具备稳定使用边界、验证证据与维护承诺。

101Preview

方向已建立，但 API、集成路线或证据仍可能变化。

23Experimental

用于验证设计假设，不应默认进入生产依赖。

升级到 Supported 的公开条件

  • 职责、依赖闭包和兼容边界明确；
  • 具备对应测试、文档和真实采用证据；
  • 破坏性变更、迁移与维护承诺可说明。

新项目如何采用

先从权威 Catalog 中选择 Supported 能力，再按实际需要增加 Preview。当前网站快照没有公开每个模块的完整生命周期映射，因此不在这里凭空给出“最小稳定组合”。

与《言铸之剑》的关系

游戏页展示的是已运行的系统事实；在公开采用清单完成前，不把同名系统自动宣称为 Sakura Framework 模块的直接使用证据。
