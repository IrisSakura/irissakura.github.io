Godot 主循环与 SceneTree 调度

沿引擎启动和单帧迭代追踪生命周期、消息队列、物理与导航服务的协作边界。

GodotRuntimeArchitecture
01 · QUESTION

问题背景

SceneTree 如何在一帧中协调节点生命周期、消息队列和引擎服务？

02 · METHOD

研究方法

沿引擎启动与单帧迭代的调用路径阅读源码，记录每一阶段的所有者。

03 · FINDING

核心发现

调度边界比单个 API 更值得复用：状态所有权、阶段顺序和延迟队列必须分开。

04 · IMPACT

对框架或游戏的影响

用于审视 Sakura Framework 的生命周期与更新调度设计，而不是复制 Godot API。
