THE RUN LOOP

一条能够反复成立的局内循环

不是单一战斗演示，而是让探索、战斗、奖励和成长彼此推进的完整游戏原型。

  1. 01

    选择房间

    在战斗、潜能、祝福等房间分支之间做出路线选择。

  2. 02

    实时战斗

    用移动、冲刺、招架与技能组合应对敌人与房间节奏。

  3. 03

    构筑成长

    潜能改变技能分支，祝福与装备继续塑造本局打法。

  4. 04

    推进与保存

    房间快照维持 Run 的连续性，支持中断后继续探索。
