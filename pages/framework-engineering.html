  • Runner、Consumer、Release 或 Production 已验证

Local Verification

local-verification

  • Consumer 已验证
  • Production 已上线

CI / Runner

ci-runner

  • 用旧 SHA 或无 SHA 日志代替 Production

Consumer Validation

Release

Production

production

权威来源production record

可以声明
  • 明确项目范围内有记录的 Production 事实

Unknown / Deferred

Unknown / Deferred

unknown-deferred

权威来源explicit boundary

可以声明
  • Unknown
  • Deferred
  • runner-pending 或未验证边界
不能声明
  • 用空白或推测填补 Production 状态
  • 跨级推断成熟度
  • Designed 与 Implemented 说明意图和存在，不替代验证证据。
