# IrisSakura Naming

> Authority: `config/brand.json`
> Public validation: `npm run test:brand`

## 名称所有权

`IrisSakura` 是唯一主品牌，用于个人身份、跨能力叙事、网站和完整生态。`IRIS × SAKURA` 是 Iris Engineering 与 Sakura Framework 同时出现时的联合锁定标志，不是第三个产品、包名、命名空间或游戏名。

`Iris *` 只命名工程工作流、项目控制、自动化、可靠性、验证和交付能力。当前正式产品名是 `Iris Engineering`。`Sakura *` 只命名可复用游戏框架、Runtime、Gameplay、Tooling、Extension、Composition 与 Integration 能力。当前正式产品名是 `Sakura Framework`。

跨研究领域的公开知识产品使用 `IrisSakura Journal`。`Consumer Lab` 是独立验证层，不进入 IRIS 或 SAKURA 家族。游戏保持自己的作品名；技术品牌只能作为小型归属说明，不能覆盖玩家首先看到的作品身份。

## 禁止与兼容

新公开内容禁止 `Iris Framework`、`Sakura Engineering`、`Sakura Project Management`、`Iris Gameplay`、`Sakura Workflow` 与 `Iris Game`。`Sakura Design Journal` 已废弃，替代名称为 `IrisSakura Journal`。历史维护文档、同步 ID `sakura-design-journal` 与兼容 URL 可以保留，但不能重新成为导航、标题、Hero 或产品卡名称。

新增产品前先判断它是能力、研究、验证还是游戏成果；无法归类时先更新品牌架构并审查，而不是临时拼接 Iris、Sakura 或 IrisSakura。命名校验只扫描公开 HTML，治理文档中的禁止词和历史说明通过明确路径保留。
