## 实际改变

- 共享动作和输入采用 8px 圆角、至少 44px 高度；首页上下按钮使用相同规格，悬停不移动点击目标。保留 `hidden`，无 JavaScript 时不展示不可用的复制按钮。
- 文章、研究库与 Framework 能力标签采用 6px 圆角、12px 字号；状态徽章保留语义颜色。
- 文字卡片采用 12px 对称圆角、20–28px 内边距、细边框，去掉硬投影和倾斜；媒体采用独立的 16px 角色。列表容器、内容图示和项目构图不强制变成卡片。
- 工具抽屉、作品详情和文章目录统一折叠箭头及焦点区域，继续使用原生 details/summary。减少动态效果偏好下立即更新箭头。
- 六项目标题共享无衬线字体及响应式档位，1440px 下为 56px；首页姓名和长文章标题保留明确的角色档位。
- Framework 参考卡片的浅底搭配深色文字，深色参考区域的介绍搭配浅色文字，修复验收发现的可读性问题。

规则入口是 `style/tokens/interface.css` 和 `style/components/interface.css`，最终共享 `interface` 层位于页面层之后。删除了首页和 notebook 中已失效的按钮特例。生成器、数据、路由和项目资产未因本批改造而改变。

## 验收中解决的问题

1. 采用列表的容器误套卡片内边距，导致窄屏列表底部留白；改为只对实际路线卡片应用容器规则。
2. 折叠箭头验收读取过早；减少动态效果模式立即更新，测试等待可观察的状态变化。
3. 研究库离屏卡片使用 content-visibility:auto；只测已渲染子树，并滚动实际卡片验证其标签，不把未渲染状态当成样式结果。
4. 旧预览标签页缓存了改造前 CSS；最终组件截图禁用缓存重拍。
5. Framework 能力标签遗漏、参考卡片旧白字及参考区介绍低对比度，均按实际发现补修；随后 axe 扫描发现的浅蓝层级数字和暖底链接对比度也已修复，扫描复验通过。
6. 新按钮 display 覆盖旧页面层的 hidden 规则；共享按钮明确遵守 hidden。
