# 个人网站开发问题备忘录

整理日期：2026-10-29。本页复用既有逐页复核和界面统一记录，按可观察问题定位。它没有重新验收页面，也不把历史本地结果提升为 Safari、实体手机、Runner 或线上 Pages 证据。

## 按症状定位

| 症状或改动 | 条目 |
| --- | --- |
| 共用组件已接入，页面仍贴边、溢出或字号不一致 | 01 样式所有权与实际边界 |
| 键盘焦点在滚动或裁剪区域消失 | 02 焦点首帧与父容器 |
| 无 JS 入口本应隐藏却出现 | 03 控件样式保留语义状态 |
| 截图与改动不符；折叠或离屏标签测量异常 | 04 浏览器状态与证据 |

## 01 class 复用不能代替逐页盒模型检查

**记录与原因。** 2026-10-27 逐页复核发现：窄屏清掉水平 padding、遗漏单列断点、长包标识挤占内容区，高层通用标题/段落规则覆盖组件字号。2026-10-29 统一中又发现列表容器误套卡片内边距，产生额外留白。

**处理与复查。** 默认排版归 base，组件几何与状态归共享组件，页面只拥有布局；按真实语义区分卡片和列表。检查窄屏、长词、混排、编号与版本行、展开内容和实际内容盒，文字进入声明 padding 即应定位，不等到越过外框。

**依据。** [逐页组件复核](site-component-review-2026-10-27.md)、[界面统一记录](ui-unification-2026-10-29.md)、[组件合同](../ui-components.md)。

## 02 焦点反馈需要覆盖初始帧

**记录与原因。** 2026-10-27 目录、筛选和搜索结果的外置 outline 被父容器裁剪，`transition: all` 还使聚焦初始帧从外侧移入，出现瞬时裁剪。

**处理与复查。** 密集或裁剪控件使用已有内置焦点 token，在普通状态即设置 offset。用键盘检查首项、末项、窄屏折行、滚动与首帧，选中、悬停、焦点含义分别保留。不能只查最终计算样式或截图里的单个中间控件。

**依据。** [逐页复核中的焦点修复](site-component-review-2026-10-27.md)、[组件边界与状态约束](../ui-components.md)。

## 03 新 display 规则必须保留 hidden 行为

**记录与原因。** 2026-10-29 新按钮的 display 覆盖旧页面层的 hidden 规则，完整 smoke 在订阅无 JS 入口发现回归。

**处理与复查。** 共享按钮明确遵守 `hidden`；在正常脚本、无 JS 和相关状态切换中验证显示与隐藏。保留首次完整命令的失败，复用未受影响的前段证据，补验订阅和尚未执行路径。不能为了新样式让本应不可见的操作暴露。

**依据。** [界面统一验收中解决的问题与复验](ui-unification-2026-10-29.md)。该批后续隔离提交候选的完整 smoke 通过，与首次中止命令分别记录。

## 04 先核对缓存、动画和可见性，再解释测量

**记录与边界。** 2026-10-29 曾出现旧标签页缓存旧 CSS、折叠箭头读取过早、`content-visibility: auto` 卡片离屏未渲染等情况。它们影响截图与测量解释，不能统一归为样式失效。

**处理与复查。** 核对当前构建和资源身份，必要时禁用缓存重拍；异步操作等待可观察状态，滚动真实卡片后再测其子树，展开后核对折叠内容。截图、实际交互和数值各说明范围，保留补修区域的新证据。

**依据。** [统一验收记录](ui-unification-2026-10-29.md)。Chromium 响应式视口只支持对应浏览器与视口结论。
