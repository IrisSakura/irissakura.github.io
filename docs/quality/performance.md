# 性能预算与实验室数据

`config/performance-budget.json` 根据 2026-09-28 本地候选构建的七个主要路由实测值制定：最大 HTML 113,221 B、CSS 318,020 B、JS 78,107 B、图片 598,940 B、48 个本地请求、索引 161,634 B。预算约束本地资源的 HTML、CSS、JS、图像和最大文件字节数、请求数量、全站搜索索引体积以及布局偏移；外部字体请求不计入本地资源预算。`npm run test:smoke` 在本地静态服务中测量首页、项目、Framework、Journal、博客、文章和联系页；逐页报告写入被忽略的 `tests/output/performance-baseline.json`。

报告中的导航时间、LCP 候选、CLS 和首页搜索响应时间是实验室观察值。脚本交互延迟用于诊断搜索与导航回归，不作为真实用户 INP。预算用于控制资源增长，不以单次不稳定的毫秒值卡住 CI。预算调整需要对照当前报告和可解释的内容变化，不能仅为消除失败而放宽。

## 2026-10-03 性能与运行时审查

审查覆盖五个浏览器运行时模块、样式加载与动画调度、页面生成器的资源入口、导航/搜索/阅读流程，以及静态站点打包。开始时已有的 Framework 内容修订保留；性能审查阶段尚未提交、推送或发布。

已处理的发现：

- CSS 通过 `main.css → site.css → 25 个 owner` 逐层发现。构建现在从同一套源文件生成 `dist/styles/site.css`，保留层顺序、选择器和资源 URL，去除注释与格式空白。各页仍保留既有兼容样式 URL。公共 CSS 由约 324 KB 降至约 273 KB，本地 CSS 请求减少 26 个。
- 首屏内容在 JS 初始化后被隐藏，再等待入场动画。现在首屏直接显示，视口外内容使用交叉观察器提供的几何结果准备入场动画；导航栏和阅读进度的初始几何读取延后，滚动期间缓存文档范围，并通过 ResizeObserver 更新。
- 花瓣之外的 Hero 背景仍持续动画。现在它们随背景动效的可见性、用户开关、减少动效设置和页面隐藏状态一起暂停。
- 第二次导航可能绕过第一次仍在加载的共享样式；较晚完成的模块可能发布过期导航事件。现在等待同一加载 Promise，提交页面前才启用新样式，清理不再需要的样式，并拒绝过期导航完成事件。
- 搜索每次输入都重复规范化所有文本；返回 Journal/Framework 时重复请求相同数据。现在预处理检索文本，并在当前文档内复用成功加载的数据，刷新页面重新读取；离开页面时清理请求、监听器和待执行动画帧。
- 搜索输入框有文字时，浏览器消耗 Escape，弹窗没有关闭。现在显式关闭弹窗并恢复触发按钮焦点，输入法组合期间保留 Escape 行为。
- 可选字体样式原先阻塞页面渲染。现在预加载并异步激活样式，监听器在插入前注册，避免缓存命中竞态；失败时正文继续显示，禁用 JS 时保留 noscript 样式入口。
