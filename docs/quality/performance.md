# 性能预算与实验室数据

`config/performance-budget.json` 根据 2026-09-28 本地候选构建的七个主要路由实测值制定：最大 HTML 113,221 B、CSS 318,020 B、JS 78,107 B、图片 598,940 B、48 个本地请求、索引 161,634 B。预算约束本地资源的 HTML、CSS、JS、图像和最大文件字节数、请求数量、全站搜索索引体积以及布局偏移；外部字体请求不计入本地资源预算。`npm run test:smoke` 在本地静态服务中测量首页、项目、Framework、Journal、博客、文章和联系页；逐页报告写入被忽略的 `tests/output/performance-baseline.json`。

报告中的导航时间、LCP 候选、CLS 和首页搜索响应时间是实验室观察值。脚本交互延迟用于诊断搜索与导航回归，不作为真实用户 INP。预算用于控制资源增长，不以单次不稳定的毫秒值卡住 CI。预算调整需要对照当前报告和可解释的内容变化，不能仅为消除失败而放宽。
