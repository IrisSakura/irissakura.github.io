## 本轮修正的失败

1. 六品牌配置使两类专用 Hero 被重复插画：增加明确 Hero 策略，只对四个组合型 Hero 注入共用构图。
2. CSS 分组清理误删仍使用的组件规则：按选择器成员拆分，保留必要样式。
3. 首页装饰伸出画布：修正装饰位置，不依赖全局隐藏横向溢出。
4. 色值迁移及深色渐变底色：恢复语义色映射和明确基色，文字对比度检查通过。
5. 测试原有的卡片、5vw 间距、直接 token link 预期已过期：改为当前结构、4vw 间距和单一分层导入入口。
6. 旋转构图的几何检查使用共同局部坐标；中文锚点比较解码后的值；兼容路由等待重定向；诊断截图等待实际绘制。

未减弱私有路径、未公开内容、错误路由、伪造下载/产品状态等原有检查。
